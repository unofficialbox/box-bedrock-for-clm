What is wrong with the current story

The presenter script sells a portfolio → intake → agent → approve → Salesforce → clause tour → Doc Gen/Sign path. That is a product feature sequence, not a contract lifecycle. Buyers map mental models to: request → paper → negotiate → approve exceptions → execute → retain.

Lifecycle order is confused Critical

Evidence

Intake already uploads a redlined MSA package, then the script later has a separate “Redlines” beat that is really a Clause Hub tour.

Why customers reject it

Legal Ops will not recognize the process. In the real world, redlines arrive after paper is exchanged — not as a dashboard sidebar visit.

Doc Gen is the wrong artifact Critical

Evidence

Live templates are approval memo, order summary, and renewal notice — not the MSA first draft the 10-step story assumes.

Why customers reject it

Claiming “we generate the contract from a DOCX template” will fail on-stage when the output is a memo, not the agreement.

Negotiation moment is underspecified High

Evidence

Steps 6–7 in the desired story (accept redlines + insert a new clause + query approved XYZ) collapse into one vague “open Clause Library” line.

Why customers reject it

This is the moment buyers care about. Without a named clause decision, the demo feels like a product feature tour, not CLM.

Status is treated as a closing slide High

Evidence

Real CLM updates status at each gate: Submitted → Under Review → In Negotiation → Pending Signature → Executed.

Why customers reject it

Sponsors ask “where does status live?” Metadata/charts only land if status moves throughout the story.

Demo claims vs live path diverge Medium

Evidence

README already warns: no Extract Agent step, no upsert/duplicate protection, Reject ends silently.

Why customers reject it

Trust collapses if the presenter narrates the architecture diagram instead of the live Automate run.

Pick one paper model (do not mix)

A. Inbound paper (matches assets) Recommended

Sales uploads Northstar’s redlined MSA package at intake. Agent compares to playbook. Human approves structured facts → Salesforce. Negotiation uses Clause Hub to resolve remaining exceptions. Doc Gen produces approval memo / order summary; final clean PDF + Sign close the deal.

Pros: works with current redline PDF, Doc Gen templates, and proven Automate path. Cons: no “we authored first paper” beat.

B. Outbound paper (matches your 10 steps) Needs new asset

Form captures deal facts only (or clean baseline). After SF create, Doc Gen emits first-draft MSA. Fast-forward: upload counterparty redlines. Accept most changes; insert one approved fallback clause; PDF → Sign → status.

Pros: classic vendor CLM story. Cons: requires an MSA Doc Gen template and a distinct returned-redline file — not what templates are today.

Default recommendation

Ship Model A for the next customer demo unless you can add a real MSA Doc Gen template this week. Rewrite the presenter script so redlines are the intake package, and the middle act is exception resolution — not “generate first draft after Salesforce.”

Make XYZ concrete

“Ask about approved clauses for XYZ” only resonates if XYZ is a named, high-stakes exception already in the sample library.

Limitation of Liability Primary

Northstar wants unlimited liability. Ask: “What is our approved liability position for a PHI deal over $1M?”

Answer from Hub: reject unlimited; use CLM-LIAB-002 (24-month cap + privacy/security super-cap). Owner: Commercial Legal.

Payment terms (optional) Secondary

Accept Net 90 with Finance condition (playbook expects Net 45). Shows commercial compromise without inventing new clauses.

Keeps one “accept redline” and one “replace with approved language” decision — the minimum realistic negotiation.

Recommended 12–15 minute arc (Model A)

0–2 min

Portfolio

Legal Ops sees every active deal by status, risk, and type — driven by governed metadata.

2–5 min

Intake + gate

Sales submits Northstar MSA package. Automate enriches; a named person approves before Salesforce is writable.

5–7 min

CRM write

Approved facts create the CLM_Contract__c record. Box remains content authority.

7–11 min

Negotiate

Fast-forward remaining exceptions. Accept payment/renewal with conditions; reject unlimited liability; pull CLM-LIAB-002 fallback from the Hub.

11–14 min

Execute + close

Generate final PDF / approval artifacts, send Box Sign after approvals clear, flip status to Executed, return to portfolio.
