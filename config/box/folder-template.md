# CLM Folder Template

Create this folder structure under each contract workspace.

```text
CLM-2026-Northstar/
├── 01 - Intake/
├── 02 - Drafts and Redlines/
├── 03 - Review Packets/
├── 04 - Approvals/
├── 05 - Signature/
├── 06 - Executed Agreement/
├── 07 - Obligations/
└── 08 - DocGen Templates/
```
