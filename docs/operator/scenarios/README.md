## Naming rule

- Use **Cross-Platform Agentic Orchestration** when a supervisor selects tools or specialist agents dynamically across platforms.
- Describe it as **supervisor-directed**. Do not describe managed integrations as live until they pass technical validation.
- Box intake, metadata, and Automate enrichment remain part of this scenario as the entry-point path; see [Entry-Point Variation](cross-platform-agentic-orchestration/supporting-react-scripts/04-box-metadata-automate-entry.md).

The scenario link opens one ordered guide: orientation, architecture, flow, presenter script, screenshots, readiness, and setup checks.
