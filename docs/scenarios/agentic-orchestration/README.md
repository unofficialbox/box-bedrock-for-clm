# Agentic Orchestration

**Supervisor-led CLM execution across the complete platform stack.** AWS Bedrock AgentCore and Strands coordinate specialist agents across Box, Agentforce, Salesforce, the Multi-Framework React workspace, and Databricks, with humans retaining approval and signature authority.

## Use this track when

- the audience wants the end-state multi-agent architecture;
- dynamic planning, specialist delegation, memory, traces, and cross-system reasoning are central;
- the Salesforce React workspace is the presenter surface;
- the demo can clearly distinguish local mocks from deployed managed services.
