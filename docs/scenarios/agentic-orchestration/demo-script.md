# Agentic Orchestration Demo Script

**Duration:** 20–25 minutes

**Audience:** Executives, enterprise architects, AI platform teams, and technical buyers

## Story

1. **Enter through the CLM dashboard or event.** The Box intake event gives the supervisor contract, workspace, and requester context.
2. **Start the AgentCore session.** Show the Strands supervisor creating a trace and deciding which specialists are required.
3. **Validate governed content.** The Box package agent checks files, metadata, versions, approved clauses, and missing evidence.
4. **Compare structured truth.** The Salesforce commercial agent reads the CLM/opportunity context and flags Net 90 in the order form against Net 45 in the record.
5. **Analyze redlines.** The clause-risk specialist produces cited findings for liability, PHI, SLA credits, renewal, and termination.
6. **Add portfolio intelligence.** The Databricks agent returns governed historical outcomes and cycle-time benchmarks; it does not overwrite the contract record.
7. **Route human experts.** The approval specialist groups findings by domain and creates or reuses Legal, Finance, Privacy, and Security work.
8. **Work in Salesforce React.** Show the Northstar workspace, live Box context, cited findings, and Agentforce conversation in one presenter surface.
9. **Demonstrate the guardrail.** A premature signature request is blocked until required approvals are complete.
10. **Complete the lifecycle.** After confirmation, generate the packet, execute through Box Sign, extract obligations, and return final state to Box and Salesforce.

## Required callouts

- AgentCore/Strands coordinates; Agentforce supplies Salesforce-native conversational and action capabilities; Box governs content.
- Databricks provides analytical context, not contract authority.
- The local trace proves contracts and routing logic, not a deployed managed-runtime claim.
- Humans approve concessions, signatures, and final obligations.
