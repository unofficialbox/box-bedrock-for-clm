# Approved Clause Library

This folder is the source for the CLM demo's governed clause library. Each approved clause is a standalone Markdown file so Box can govern, search, preview, classify, and publish it independently.

## Publishing model

- Upload the files under `approved/` to the live Box `09 - Clause Library/Approved` folder.
- Apply the `CLM Clause` metadata template to each file.
- Publish the approved folder and selected clause files to the `Acme Contract Clause Library` Hub.
- Keep fallback language visually distinct from the standard position.
- Use the `lastReviewed`, `nextReview`, and `usageCount` metadata to make the Hub and Box App feel operational rather than static.

The clause text is fictional and demo-only. It is not legal advice.
